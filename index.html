01 — เกี่ยวกับฉัน

รู้จักผมมากขึ้น.

ผมเป็นนักศึกษาเทคโนโลยีสารสนเทศที่ชอบเรียนรู้ผ่านการลงมือทำ และสนุกกับการแก้ปัญหาด้วยโค้ด

เริ่มต้นสนใจการพัฒนาเว็บจากความอยากสร้างเว็บไซต์ของตัวเอง จากนั้นก็ค่อย ๆ ศึกษา HTML, CSS และ JavaScript ไปจนถึงการเขียนฝั่งเซิร์ฟเวอร์ ด้วย Node.js และ Express ทุกวันนี้ยังคงฝึกทำโปรเจกต์เล็ก ๆ อยู่เสมอ เพื่อให้เข้าใจทั้งการออกแบบและตรรกะการทำงานเบื้องหลัง

เป้าหมายของผมคือการเป็นนักพัฒนาเว็บที่สร้างงานคุณภาพ ใช้งานง่าย และเข้าถึงได้สำหรับทุกคน หากคุณกำลังมองหาคนที่พร้อมเรียนรู้และทุ่มเท ผมยินดีมากที่จะได้ร่วมงานด้วย

เรียนรู้เร็ว พร้อมปรับตัวกับเครื่องมือใหม่ ๆ
ใส่ใจรายละเอียด ให้ความสำคัญกับ UX และความเรียบร้อย
ทำงานเป็นทีม สื่อสารชัดเจนและรับฟังความคิดเห็น

  • CRUD
