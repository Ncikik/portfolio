01 · ไฟล์

วางไฟล์ให้ถูกตำแหน่ง

โฟลเดอร์โปรเจกต์/
├── index.html  ← ต้องอยู่ root
├── style.css
├── script.js
├── favicon.svg
└── assets/
    └── images/
        ├── profile.jpg
        └── project-1.jpg

ชื่อไฟล์ควรเป็นภาษาอังกฤษตัวเล็ก ไม่มีเว้นวรรค และระวังตัวพิมพ์เล็ก-ใหญ่ให้ตรงกับที่เขียนใน HTML

03 · รูปภาพ

ใส่รูปของคุณเอง

สร้างโฟลเดอร์ assets/images/ แล้ววางรูป จากนั้นแก้บล็อก photo-placeholder เป็น:

<img src="assets/images/profile.jpg"
     alt="รูปโปรไฟล์ของฉัน">

รูปโปรไฟล์ ~800×800 px, รูปผลงาน 16:9 (~1200×675 px) และบีบอัดให้เล็กกว่า 300 KB ต่อรูป

ปรับสีได้ในที่เดียว

ขั้นตอนที่ 1–5

อัปขึ้น GitHub.

ทำตามลำดับนี้โดยใช้เมาส์และหน้าจอทั้งหมด ไม่ต้องพิมพ์คำสั่งใด ๆ ชื่อปุ่มอาจต่างกันเล็กน้อยตามเวอร์ชันของ GitHub Desktop

สมัคร GitHub และติดตั้ง GitHub Desktop

สมัครที่ github.com → ยืนยันอีเมล → ดาวน์โหลดจาก desktop.github.com → เปิดโปรแกรมแล้วกด Sign in to GitHub.com

ย้ายโปรเจกต์ออกจาก OneDrive

คัดลอกโฟลเดอร์เว็บไปไว้ที่ C:\Projects\portfolio เพื่อลดปัญหาไฟล์ถูกล็อกหรือซิงก์ชนกับ Git

ถ้าไม่มีโฟลเดอร์ ให้สร้างใหม่ใน File Explorer ได้เลย

สร้าง Repository ใน GitHub Desktop

ไปที่ File → New repository… แล้วกรอก:

Name: ชื่อผู้ใช้github.github.io (เช่น somchai.github.io)
Local path: C:\Projects
Initialize with README: ไม่ต้องติ๊ก

กด Create repository แล้วคัดลอกไฟล์เว็บทั้งหมดไปวางในโฟลเดอร์ที่สร้าง

Commit ไฟล์ทั้งหมด

กลับมาที่ GitHub Desktop → แท็บ Changes → ช่อง Summary พิมพ์ First commit → กด Commit to main

ถ้าเห็นไฟล์ครบทั้ง HTML, CSS, JS และรูป แปลว่าพร้อมเผยแพร่

Publish repository

กด Publish repository ด้านบน → เอาติ๊ก “Keep this code private” ออก → กด Publish repository อีกครั้ง

ขั้นตอนที่ 6–7

เปิด Pages และอัปเดตเว็บ.

หลัง Publish repository แล้ว เหลือเปิด GitHub Pages อีกขั้นเดียว เว็บจะออนไลน์ภายใน 1–3 นาที

6 เปิด GitHub Pages

ใน GitHub Desktop กด Repository → View on GitHub แล้วทำตามนี้:

Settings → เมนูซ้าย Pages
Source: Deploy from a branch
Branch: main  ·  Folder: / (root)
กด Save แล้วรอ 1–3 นาที

URL https://ชื่อผู้ใช้.github.io/

7 อัปเดตเว็บในอนาคต

แก้ไฟล์ในโฟลเดอร์ → เปิด GitHub Desktop → แท็บ Changes → พิมพ์ Summary → Commit to main → Push origin

รอ 1–2 นาที แล้วกด Ctrl + F5 ที่หน้าเว็บ

✓ ครั้งต่อไปใช้แค่ Commit → Push origin ไม่ต้องสร้าง repo ใหม่

ถ้าเจอปัญหา

อาการวิธีแก้
เปิดแล้วขึ้น 404รอ 2–3 นาที · ตรวจ index.html อยู่ root · ตรวจ branch เป็น main · ตรวจว่า Pages ถูกเปิดแล้ว
CSS หรือรูปไม่โหลดตรวจชื่อไฟล์ตัวพิมพ์เล็ก-ใหญ่ · ใช้ path assets/images/... โดยไม่มี / นำหน้า
แก้แล้วเว็บไม่เปลี่ยนรอ 1–2 นาที · กด Ctrl + F5 · ตรวจว่ากด Push origin สำเร็จ
GitHub ไม่ยอมเปิด Pagesrepository ต้องเป็น Public (แพ็กเกจฟรี) · ตรวจอีเมลยืนยันแล้ว
Commit ไม่ได้ปิดโปรแกรมที่เปิดไฟล์อยู่ · ย้ายโปรเจกต์ออกจาก OneDrive
✓ เช็กก่อนส่งงาน: เปิดเว็บจริงบนมือถือ · กดเมนูครบทุกข้อ · ทดสอบโหมดมืด/สว่าง · กดลิงก์อีเมล/GitHub/Facebook/LINE · ตรวจว่าไม่มีคำว่า example.com หรือ yourusername เหลืออยู่
