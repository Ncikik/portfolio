โฟลเดอร์สำหรับรูปภาพของคุณ
============================

วางไฟล์รูปในโฟลเดอร์นี้ แล้วแก้ path ใน index.html ให้ตรงกับชื่อไฟล์

ตัวอย่าง:
- profile.jpg      → รูปโปรไฟล์ (แนะนำ ~800 x 800 px)
- project-1.jpg    → รูปผลงานชิ้นที่ 1 (แนะนำ 16:9 ~1200 x 675 px)
- project-2.jpg    → รูปผลงานชิ้นที่ 2
- project-3.jpg    → รูปผลงานชิ้นที่ 3
- project-4.jpg    → รูปผลงานชิ้นที่ 4

ข้อควรระวัง:
1. ใช้รูปของคุณเอง หรือรูปฟรีที่ได้รับอนุญาต (เช่น Unsplash / Pexels)
2. ห้ามใช้รูป โลโก้ หรือตัวละครที่มีลิขสิทธิ์
3. ตั้งชื่อไฟล์เป็นภาษาอังกฤษตัวเล็ก ไม่มีเว้นวรรค
4. บีบอัดรูปก่อนอัปโหลด (เช่น squoosh.app) ให้แต่ละไฟล์ไม่เกิน ~300 KB
5. ใส่ alt เป็นคำอธิบายรูปจริง เพื่อการเข้าถึงที่ดี

วิธีเปลี่ยนรูปโปรไฟล์:
ค้นหา "photo-placeholder" ใน index.html แล้วแทนบล็อกนั้นด้วย
<img src="assets/images/profile.jpg" alt="รูปโปรไฟล์ของชื่อ-นามสกุล">

วิธีเปลี่ยนรูปผลงาน:
เพิ่ม <img> ไว้ใน .project-thumb แล้วลบ svg.thumb-icon กับ span.thumb-caption ออก
ดูตัวอย่างทั้งหมดได้ใน README.md หัวข้อ "เปลี่ยนรูปโปรไฟล์และรูปผลงาน"
