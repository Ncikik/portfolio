# Portfolio ส่วนตัว — HTML + CSS + JavaScript

เว็บพอร์ตโฟลิโอหน้าเดียว (Single Page) ที่เขียนด้วย HTML, CSS และ JavaScript ล้วน
ไม่ใช้เฟรมเวิร์ก ไม่ต้องติดตั้งอะไรเพิ่ม และนำไปฝากฟรีบน **GitHub Pages** ได้
ออกแบบให้รองรับมือถือ มีโหมดสว่าง/มืด เลื่อนนุ่มนวล และมีแอนิเมชันเบา ๆ ตอนเลื่อนหน้า

> ไฟล์ทั้งหมดเป็นโค้ดของคุณเอง 100% ไม่มีรูป โลโก้ หรือตัวละครที่มีลิขสิทธิ์
> ไอคอนใช้ชุด **Lucide** (สัญญาอนุญาต ISC ใช้เชิงพาณิชย์ได้) ฝังเป็น SVG ในไฟล์ HTML
> ฟอนต์ใช้ **Prompt** และ **Noto Sans Thai** จาก Google Fonts

## 1. ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงสร้างเนื้อหาทั้งหมด + ไอคอน SVG + คอมเมนต์จุดที่ต้องแก้ |
| `style.css` | ดีไซน์ สี ฟอนต์ Responsive โหมดมืด และแอนิเมชัน |
| `script.js` | สลับธีม เมนูมือถือ Scroll spy แอนิเมชันตอนเลื่อน คัดลอกอีเมล |
| `editor.css` / `editor.js` | โหมดแก้ไขข้อมูลในเบราว์เซอร์ (โหลดเฉพาะตอนเปิดในเครื่อง หรือเติม `?edit=1`) |
| `favicon.svg` | ไอคอนแท็บเบราว์เซอร์ (วาดเอง แก้สีได้) |
| `guide.html` | คู่มือขึ้น GitHub Pages ฉบับพิมพ์ได้ (กดปุ่มเพื่อบันทึกเป็น PDF) |
| `deploy-guide.pdf` / `deploy-guide.png` | คู่มือขึ้น GitHub Pages แบบไฟล์พร้อมใช้ (ถ้ามีในโฟลเดอร์) |
| `README.md` | คู่มือฉบับข้อความ (ไฟล์นี้) |

> **ก่อนอัปขึ้น GitHub Pages** ต้องมี `index.html` อยู่ที่ "root" ของ repository
> และ repository ต้องเป็น **Public** (แพ็กเกจฟรี)

## 2. เปิดดูเว็บในเครื่อง

วิธีง่ายที่สุด:

1. ดับเบิลคลิก `index.html`
2. เว็บจะเปิดในเบราว์เซอร์ทันที

แนะนำให้ใช้ **VS Code + ส่วนขยาย Live Server** เพื่อดูการเปลี่ยนแปลงแบบเรียลไทม์:

1. ติดตั้ง [VS Code](https://code.visualstudio.com/)
2. เปิดโฟลเดอร์โปรเจกต์นี้
3. ติดตั้งส่วนขยาย **Live Server**
4. คลิกขวาที่ `index.html` → **Open with Live Server**

> เปิดด้วย `file://` ก็ใช้งานได้เกือบทั้งหมด แต่ปุ่มคัดลอกอีเมลอาจถูกเบราว์เซอร์จำกัด
> และฟอนต์ Google Fonts ต้องต่ออินเทอร์เน็ต

## 3. แก้ข้อความทั้งหมด (จุดที่ต้องเปลี่ยน)

> ถ้าไม่อยากแตะโค้ดเลย ข้ามไปใช้ **โหมดแก้ไขข้อมูลในเบราว์เซอร์** ที่ข้อ 11 ได้
> (แก้ข้อความและอัปโหลดรูปผ่านหน้าเว็บ แล้วดาวน์โหลด `index.html` ไปอัปทับ)

ใช้ **Ctrl + F** (ค้นหา) หรือ **Ctrl + H** (ค้นหาและแทนที่) ใน VS Code
ค้นคำเหล่านี้แล้วแทนด้วยข้อมูลจริงของคุณ:

| ค้นหา | แทนด้วย | หมายเหตุ |
|---|---|---|
| `ชื่อ-นามสกุล` | ชื่อและนามสกุลของคุณ | ปรากฏใน title, navbar, hero, footer |
| `your.email@example.com` | อีเมลจริง | มีหลายจุด รวมปุ่มคัดลอก |
| `yourusername` | ชื่อผู้ใช้ GitHub | ใช้กับลิงก์ GitHub |
| `facebook.com/yourusername` | ลิงก์ Facebook ของคุณ | หรือลบทิ้งถ้าไม่ใช้ |
| `@yourlineid` | LINE ID ของคุณ | ลิงก์ LINE ใช้ `https://line.me/ti/p/~yourlineid` |
| `CN` | อักษรย่อชื่อของคุณ | ตัวอักษรในกล่องรูปโปรไฟล์ |
| `IT Student · Web Developer` | ตำแหน่ง/คำอธิบายสั้น | ใต้ชื่อใน profile card |
| `ปวส. เทคโนโลยีสารสนเทศ` | ระดับการศึกษา/สาขาของคุณ | Hero + About |
| `Junior Web Developer` | เป้าหมายอาชีพ | About |
| `ประเทศไทย` | จังหวัด/ประเทศของคุณ | About |

### เปลี่ยนคำสรรพนาม (ผม / ฉัน / ครับ / ค่ะ)

โค้ดตัวอย่างใช้ผู้ชาย (`ผม`, `ครับ`) ถ้าเป็นผู้หญิงให้ค้นและแทนที่:

- `ผม` → `ฉัน` (หรือ `หนู`)
- `ครับ` → `ค่ะ`

ตรวจสอบทุกจุดใน `index.html` โดยเฉพาะ Hero, About และ Contact

### จุดที่คอมเมนต์บอกไว้

ใน `index.html` มีคอมเมนต์ภาษาไทย เช่น:

```html
<!-- แก้ไขคำแนะนำตัว 2–3 ประโยคตรงนี้ -->
<!-- แก้ไขลิงก์ติดต่อทั้ง 3 ช่องทาง -->
<!-- แก้ไขชื่อที่แสดงบนโลโก้ -->
```

สามารถค้นคำว่า `แก้ไข` เพื่อดูจุดสำคัญทั้งหมดได้เลย

## 4. เปลี่ยนรูปโปรไฟล์และรูปผลงาน

### 4.1 เตรียมโฟลเดอร์รูป

สร้างโฟลเดอร์:

```
Default Project/
├── index.html
├── style.css
├── script.js
├── favicon.svg
└── assets/
    └── images/
        ├── profile.jpg
        ├── project-1.jpg
        ├── project-2.jpg
        ├── project-3.jpg
        └── project-4.jpg
```

**ข้อแนะนำเรื่องรูป**

- ใช้รูปของคุณเอง หรือรูปฟรีจาก Unsplash / Pexels ที่ได้รับอนุญาต
- ห้ามใช้รูป โลโก้ หรือตัวละครที่มีลิขสิทธิ์
- รูปโปรไฟล์แนะนำขนาดประมาณ **800 × 800 px** ขึ้นไป
- รูปผลงานแนะนำอัตราส่วน **16:9** เช่น **1200 × 675 px**
- บีบอัดรูปก่อนอัปโหลด (เช่น [squoosh.app](https://squoosh.app/)) ให้ไฟล์ไม่เกิน ~300 KB/รูป
- ตั้งชื่อไฟล์เป็นภาษาอังกฤษตัวเล็ก ไม่มีเว้นวรรค เช่น `project-1.jpg`

### 4.2 เปลี่ยนรูปโปรไฟล์

ค้นหา `photo-placeholder` ใน `index.html` จะเจอบล็อกนี้:

```html
<div class="photo-placeholder" role="img" aria-label="พื้นที่สำหรับรูปโปรไฟล์ของคุณ">
  <span class="photo-initials" aria-hidden="true">CN</span>
  <span class="photo-note">วางรูปโปรไฟล์ของคุณที่นี่</span>
</div>
```

ให้ **ลบทั้งบล็อก** แล้วใส่ `<img>` แทน:

```html
<img src="assets/images/profile.jpg" alt="รูปโปรไฟล์ของชื่อ-นามสกุล">
```

วางไว้ใน `<div class="profile-photo">` แทนที่บล็อกเดิม โดยเก็บ `.profile-badge` ไว้:

```html
<div class="profile-photo">
  <img src="assets/images/profile.jpg" alt="รูปโปรไฟล์ของชื่อ-นามสกุล">
  <span class="profile-badge">
    <span class="status-dot" aria-hidden="true"></span>
    พร้อมเรียนรู้
  </span>
</div>
```

> CSS มี `.profile-photo > img` เตรียมไว้แล้ว รูปจะถูกครอปให้พอดีกรอบอัตโนมัติ

### 4.3 เปลี่ยนรูปผลงาน

ในแต่ละ `.project-thumb` ให้เพิ่ม `<img>` เป็นลูกแรก แล้วลบ `svg.thumb-icon`
กับ `span.thumb-caption` ออก (เก็บ `.thumb-number` ไว้ได้):

```html
<div class="project-thumb thumb-1" role="img" aria-label="ภาพตัวอย่างโปรเจกต์เว็บจัดการรายรับรายจ่าย">
  <img src="assets/images/project-1.jpg" alt="หน้าจอเว็บจัดการรายรับรายจ่าย" loading="lazy">
  <span class="thumb-number">01</span>
</div>
```

ทำแบบเดียวกันกับ `project-2.jpg`, `project-3.jpg`, `project-4.jpg`
ถ้ายังไม่มีรูป ให้ใช้กล่องสีเดิมไปก่อนได้เลย ไม่ต้องแก้อะไร

## 5. เปลี่ยนสีให้เป็นโทนของคุณ

สีทั้งหมดรวมอยู่ที่ต้นไฟล์ `style.css` ใน `:root` (โหมดสว่าง) และ
`html[data-theme="dark"]` (โหมดมืด) แก้แค่ไม่กี่ตัวก็เปลี่ยนทั้งเว็บ:

```css
:root {
  --bg: #f6f8fc;          /* พื้นหลังหน้าเว็บ */
  --surface: #ffffff;     /* พื้นหลังการ์ด */
  --text: #0c1a32;        /* สีตัวอักษรหลัก */
  --muted: #5a6b85;       /* สีตัวอักษรรอง */
  --border: #dbe4f2;      /* สีเส้นขอบ */
  --primary: #1d4ed8;     /* สีหลัก (ปุ่ม/ลิงก์) */
  --primary-2: #0ea5e9;   /* สีไล่ระดับ */
  --on-primary: #ffffff;  /* สีตัวอักษรบนปุ่มหลัก */
}
```

โหมดมืด:

```css
html[data-theme="dark"] {
  --bg: #07101f;
  --surface: #0e1b30;
  --text: #e9f0fc;
  --primary: #6ea8fe;
  --primary-2: #38bdf8;
  --on-primary: #06101f;
}
```

**ตัวอย่างโทนอื่น**

| โทน | `--primary` | `--primary-2` | `--bg` |
|---|---|---|---|
| น้ำเงินเข้ม + ขาว (ค่าเริ่มต้น) | `#1d4ed8` | `#0ea5e9` | `#f6f8fc` |
| เขียว Emerald + ขาว | `#047857` | `#10b981` | `#f7fbf9` |
| ม่วง + ขาว | `#6d28d9` | `#a855f7` | `#faf8ff` |
| ส้มอิฐ + ครีม | `#c2410c` | `#f97316` | `#fdf9f5` |

> ถ้าเปลี่ยนสีหลักแล้ว อย่าลืมแก้ `themeColors` ใน `script.js`
> (`#f6f8fc` และ `#07101f`) ให้ตรงกับสีพื้นหลังใหม่ และแก้
> `<meta name="theme-color">` ใน `index.html` ด้วย
>
> ควรเลือกสีตัวอักษรบนปุ่มให้ตัดกับสีพื้นหลัง (`--on-primary`) เพื่อให้อ่านง่าย

### เปลี่ยนฟอนต์

1. เปิด [Google Fonts](https://fonts.google.com/?subset=thai) เลือกฟอนต์ที่รองรับภาษาไทย
   เช่น `Prompt`, `Noto Sans Thai`, `Kanit`, `Sarabun`, `IBM Plex Sans Thai`
2. แก้ `<link>` ของ Google Fonts ใน `index.html`
3. แก้ตัวแปรใน `style.css`:

```css
--font-heading: "Kanit", "Noto Sans Thai", sans-serif;
--font-body: "Sarabun", "Noto Sans Thai", sans-serif;
```

## 6. เพิ่ม/ลบผลงาน และแก้ลิงก์

### เพิ่มการ์ดผลงาน

คัดลอก `<article class="project-card reveal"> ... </article>` ทั้งบล็อก
แล้ววางต่อจากใบสุดท้าย จากนั้นแก้:

- `thumb-1` → `thumb-2` / `thumb-3` / `thumb-4` (สลับโทนสี)
- `01` → `05`
- ชื่อโปรเจกต์, คำอธิบาย, แท็กเทคโนโลยี
- `href="https://example.com"` → ลิงก์เว็บจริง
- `href="https://github.com/yourusername"` → ลิงก์โค้ดจริง

ถ้าไม่มีการ์ดเป็นจำนวนคู่ Grid 2 คอลัมน์อาจเหลือช่องว่าง 1 ช่อง
สามารถเพิ่มให้เป็น 6 ใบ หรือแก้ `.projects-grid` เป็น 3 คอลัมน์บนจอใหญ่ได้

### ลบผลงาน

ลบ `<article class="project-card reveal"> ... </article>` ทั้งบล็อกออก

### เปลี่ยนลิงก์ที่ยังเป็นตัวอย่าง

ค้นหา `example.com` และ `github.com/yourusername` แล้วแทนให้หมด
ถ้าโปรเจกต์ไหนยังไม่มีเว็บจริง ให้ลบปุ่ม "ดูตัวอย่าง" ออก หรือเปลี่ยนเป็นข้อความ
"กำลังพัฒนา" แทนการปล่อยลิงก์ที่ใช้ไม่ได้

## 7. ทดสอบก่อนเผยแพร่

- [ ] เปิดเว็บแล้วไม่มีข้อความ placeholder (`ชื่อ-นามสกุล`, `your.email@...`, `example.com`)
- [ ] ลิงก์เมนูทั้ง 4 ข้อเลื่อนไปถูกส่วน
- [ ] ปุ่มโทรศัพท์/อีเมล/โซเชียลกดได้จริง
- [ ] ปุ่มคัดลอกอีเมลทำงาน
- [ ] ปุ่มสลับโหมดสว่าง/มืดทำงาน และจำค่าได้หลังรีเฟรช
- [ ] เปิดบนมือถือ (หรือย่อหน้าต่าง) แล้วเมนูไม่ล้น ไม่อ่านยาก
- [ ] รูปทั้งหมดมี `alt` และโหลดได้
- [ ] กด Tab ใช้งานเว็บได้ (มีกรอบโฟกัสชัดเจน)
- [ ] เปิดด้วย `Ctrl + F5` แล้วยังปกติ

## 8. นำขึ้น GitHub Pages ฟรี (ไม่ต้องพิมพ์คำสั่ง)

> **คู่มือแบบภาพ:** เปิด `guide.html` แล้วกดปุ่ม **“พิมพ์ / บันทึกเป็น PDF”**
> มุมขวาล่าง จากนั้นเลือก **Save as PDF** ในหน้าต่างพิมพ์
> (หรือกด `Ctrl + P` แล้วเลือก Save as PDF)
> ไฟล์ `deploy-guide.pdf` / `deploy-guide.png` ที่แนบมาคือคู่มือชุดเดียวกัน

วิธีนี้ใช้ **GitHub Desktop** ทั้งหมด ไม่ต้องใช้ Terminal และไม่ต้องพิมพ์โค้ดบนเว็บ
ทำครั้งแรกประมาณ 10–15 นาที

### ขั้นที่ 1: เตรียมบัญชี

1. สมัคร/เข้าสู่ระบบ [github.com](https://github.com/)
2. ยืนยันอีเมลให้เรียบร้อย
3. ดาวน์โหลด [GitHub Desktop](https://desktop.github.com/) แล้วติดตั้ง
4. เปิด GitHub Desktop → **Sign in to GitHub.com** → อนุมัติในเบราว์เซอร์

### ขั้นที่ 2: ย้ายโปรเจกต์ออกจาก OneDrive (แนะนำ)

โฟลเดอร์นี้อยู่ใน OneDrive ซึ่งอาจทำให้ไฟล์ถูกล็อกหรือซิงก์ชนกับ Git
แนะนำให้คัดลอกโฟลเดอร์ไปไว้ที่:

```
C:\Projects\portfolio
```

หรือจะลองใช้ใน OneDrive ก่อนก็ได้ แต่ถ้าเจอปัญหาไฟล์ค้าง/คอมมิตไม่ได้ ให้ย้ายออก

### ขั้นที่ 3: สร้าง Repository

1. เปิด GitHub Desktop
2. เมนู **File → New repository…**
3. กรอก:
   - **Name:** `ชื่อผู้ใช้github.github.io` เช่น `somchai.github.io`
     - ต้องเป็นชื่อผู้ใช้ GitHub ของคุณตามด้วย `.github.io` เท่านั้น (ตัวพิมพ์เล็ก)
     - ถ้าอยากได้ URL แบบมีชื่อโปรเจกต์ ให้ตั้งชื่ออื่น เช่น `portfolio`
   - **Description:** `My personal portfolio` (ไม่ใส่ก็ได้)
   - **Local path:** `C:\Projects`
   - **Initialize with README:** ไม่ต้องติ๊ก
   - **Git ignore:** None
   - **License:** None
4. กด **Create repository**
5. เปิดโฟลเดอร์ที่สร้างขึ้น แล้วคัดลอกไฟล์เหล่านี้จากโปรเจกต์เดิมไปวาง:
   - `index.html`
   - `style.css`
   - `script.js`
   - `favicon.svg`
   - โฟลเดอร์ `assets` (ถ้ามีรูป)
   - `editor.css` และ `editor.js` (ไม่บังคับ — ใส่ไว้ถ้าอยากใช้โหมดแก้ไขข้อมูลในเครื่องต่อ)

> คัดลอกเฉพาะไฟล์ของพอร์ตโฟลิโอเท่านั้น ถ้าโฟลเดอร์ต้นทางมีโปรเจกต์อื่นปนอยู่
> (เช่นโฟลเดอร์แอปอื่น) ไม่ต้องคัดลอกไป เพราะทุกไฟล์ใน repository จะถูกเผยแพร่สู่สาธารณะ
6. กลับมาที่ GitHub Desktop จะเห็นไฟล์ทั้งหมดในแท็บ **Changes**

### ขั้นที่ 4: Commit และ Publish

1. ช่อง **Summary** ด้านซ้ายล่างพิมพ์: `First commit`
2. กด **Commit to main**
3. กดปุ่ม **Publish repository** ด้านบน
4. **เอาติ๊ก "Keep this code private" ออก** (GitHub Pages ฟรีต้องเป็น Public)
5. กด **Publish repository**

### ขั้นที่ 5: เปิด GitHub Pages

1. ใน GitHub Desktop กด **Repository → View on GitHub** (หรือเปิดเว็บ github.com)
2. ในหน้า repository กด **Settings** (แถบด้านบน)
3. เมนูด้านซ้าย เลือก **Pages**
4. หัวข้อ **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. กด **Save**
6. รอ 1–3 นาที แล้วรีเฟรชหน้า Pages
7. จะเห็นลิงก์เว็บของคุณ:

| ชื่อ repository | URL ที่ได้ |
|---|---|
| `ชื่อผู้ใช้.github.io` | `https://ชื่อผู้ใช้.github.io/` |
| `portfolio` | `https://ชื่อผู้ใช้.github.io/portfolio/` |

เช่น `somchai.github.io` → `https://somchai.github.io/`

> ถ้าเปิดแล้วขึ้น 404 ให้รออีก 2–3 นาที แล้วกด `Ctrl + F5`
> ตรวจว่า `index.html` อยู่ที่ root และชื่อไฟล์เป็นตัวพิมพ์เล็กทั้งหมด

### ขั้นที่ 6: อัปเดตเว็บในอนาคต

1. แก้ไฟล์ในโฟลเดอร์โปรเจกต์ (เช่น `index.html`)
2. เปิด GitHub Desktop จะเห็นการเปลี่ยนแปลงในแท็บ **Changes**
3. พิมพ์ Summary เช่น `Update about section`
4. กด **Commit to main**
5. กด **Push origin**
6. รอ 1–2 นาที แล้วรีเฟรชเว็บด้วย `Ctrl + F5`

### ถ้าเจอปัญหา

| อาการ | วิธีแก้ |
|---|---|
| เปิดเว็บแล้ว 404 | รอ 2–3 นาที / ตรวจว่า `index.html` อยู่ root / ตรวจชื่อ branch เป็น `main` / ตรวจว่า Pages เปิดแล้ว |
| CSS หรือรูปไม่โหลด | ตรวจชื่อไฟล์และตัวพิมพ์เล็ก-ใหญ่ให้ตรงกัน / ใช้ path แบบ `assets/images/...` ไม่มี `/` นำหน้า |
| อัปเดตแล้วเว็บไม่เปลี่ยน | รอ 1–2 นาที / กด `Ctrl + F5` / ดูว่า Push origin สำเร็จหรือยัง |
| GitHub Pages ไม่เปิดให้ | repository ต้องเป็น Public (แพ็กเกจฟรี) |
| ฟอนต์ไทยไม่โหลด | ตรวจอินเทอร์เน็ต / Google Fonts อาจถูกบล็อกในบางเครือข่าย ระบบจะใช้ฟอนต์สำรองให้ |
| คอมมิตไม่ได้เพราะไฟล์ถูกใช้อยู่ | ปิดโปรแกรมที่เปิดไฟล์ / ย้ายโปรเจกต์ออกจาก OneDrive |
| อยากใช้โดเมนตัวเอง | Settings → Pages → Custom domain (ไม่จำเป็นสำหรับเริ่มต้น) |

> **ห้ามใส่รหัสผ่าน API key หรือข้อมูลลับในไฟล์** เพราะเว็บ Public ทุกคนเห็นโค้ดได้

### ทางเลือกสำรอง: อัปโหลดผ่านหน้าเว็บ GitHub

ถ้าไม่อยากติดตั้ง GitHub Desktop:

1. สร้าง repository ใหม่บน github.com
2. กด **Add file → Upload files**
3. ลากไฟล์ทั้งหมด (รวมโฟลเดอร์ `assets`) ไปวาง
4. กด **Commit changes**
5. ไปที่ Settings → Pages → เลือก `main` / `/ (root)` → Save

## 11. โหมดแก้ไขข้อมูลในเบราว์เซอร์ (ไม่ต้องแตะโค้ด)

ในโปรเจกต์มีโหมดแก้ไขข้อมูลสำเร็จรูปมาด้วย เหมาะกับตอนที่ต้องการเปลี่ยนข้อความ
หรือรูปเร็ว ๆ โดยไม่ต้องเปิดไฟล์ HTML เลย

### วิธีเปิด

| วิธี | ทำอย่างไร |
|---|---|
| เปิดในเครื่อง | ดับเบิลคลิก `index.html` (หรือเปิดด้วย Live Server) จะเห็นปุ่ม **“แก้ไขข้อมูล”** ลอยมุมขวาล่าง |
| เปิดบนเว็บที่เผยแพร่แล้ว | เติม `?edit=1` ท้าย URL เช่น `https://yourusername.github.io/?edit=1` |

### ขั้นตอนใช้งาน

1. กดปุ่ม **แก้ไขข้อมูล** จะมีแผงฟอร์มเลื่อนออกมาจากด้านขวา
2. แก้ข้อความทุกจุด (ชื่อ, คำแนะนำตัว, การศึกษา, ผลงาน, ช่องทางติดต่อ ฯลฯ)
3. อัปโหลด **รูปโปรไฟล์ / รูปผลงาน** ได้จากในแผง — ระบบจะย่อขนาดให้อัตโนมัติ
   (สูงสุด 900px สำหรับรูปโปรไฟล์ และ 1200px สำหรับรูปผลงาน)
4. กด **บันทึก** เพื่อดูผลทันทีในเบราว์เซอร์นี้
5. กด **ดาวน์โหลด index.html** เพื่อได้ไฟล์ที่ฝังข้อมูลใหม่ไว้แล้ว
6. นำไฟล์นั้นไปทับ `index.html` เดิม (ในโฟลเดอร์โปรเจกต์) แล้วอัปขึ้น GitHub ตามข้อ 8

### สิ่งที่ต้องรู้

- ปุ่ม **บันทึก** เก็บข้อมูลไว้ใน `localStorage` ของเบราว์เซอร์ที่ใช้แก้เท่านั้น
  **ผู้ชมเว็บจะไม่เห็นการเปลี่ยนแปลง** จนกว่าคุณจะอัปโหลด `index.html` ที่ดาวน์โหลดไปแล้ว
- รูปที่อัปโหลดจะถูกแปลงเป็น base64 ฝังใน `index.html` ทำให้ไฟล์ใหญ่ขึ้น
  ถ้าใช้รูปหลายรูปและอยากให้เว็บโหลดเร็ว ควรใช้วิธีในข้อ 4 (วางไฟล์ใน `assets/images`) แทน
- ปุ่ม **ล้างข้อมูลที่แก้ไข** จะลบข้อมูลในเบราว์เซอร์และกลับไปใช้ค่าตั้งต้นใน `index.html`
- โหมดนี้ถูกโหลดเฉพาะตอนเปิดในเครื่องหรือเมื่อมี `?edit=1` เท่านั้น
  ผู้เข้าชมทั่วไปจึงไม่ต้องโหลด `editor.css` / `editor.js` และความเร็วเว็บไม่ลดลง
- ไฟล์ `index.html` ที่ดาวน์โหลดออกมาจะยังมีโค้ดส่วนโหลดโหมดแก้ไขติดไปด้วย (โดยตั้งใจ)
  เพื่อให้ครั้งต่อไปยังใช้โหมดนี้ได้อีก — แต่จะไม่ทำงานกับผู้ชมทั่วไป
